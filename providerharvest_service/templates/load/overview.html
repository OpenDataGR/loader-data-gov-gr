Load Box

Where a source's result goes: one switch, Publish, and one public address per source, /data/<name>. A source that stores data (a push source with a transform) answers with its newest good output -- the address a CKAN resource can link to. An API source stores nothing: the provider is asked at the moment someone calls, with the source's credential, its request settings and its transform. Nothing is published until you switch it on, and only an active source answers.
