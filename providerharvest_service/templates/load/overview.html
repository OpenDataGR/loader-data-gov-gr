Load Box

Where a pipeline's result goes. A pipeline has any number of outputs, each one way and each on its own line: a public address on this loader (/data/<source>/<pipeline>, and the source's default pipeline also at /data/<source>), and any number of loads into CKAN (a link, an uploaded copy, rows in a DataStore table, a data service). A pipeline of a source that stores data answers at its address with its newest good output; a pipeline of an API source stores nothing: the provider is asked at the moment someone calls, with the source's credential and the pipeline's request settings (a pipeline that is switched off, or has no steps, passes the provider's answer through unchanged). Nothing is public until you add the public address, and only an active source answers.
