Load Box

Where a source's result goes. There are two ways out. A published source gives its newest transformed output a fixed public address that anyone can call -- or that a CKAN resource can link to -- and it always answers with the latest good output; nothing is published until you switch it on. A live proxy passes each call straight through to the provider: nothing is stored or transformed on the way. A live proxy is set on the source itself (Extract Box); it is shown here so the whole path is visible.
