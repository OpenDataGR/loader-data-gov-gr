Load Box

Where a pipeline's result goes: one switch, Publish, and one public address per pipeline -- /data/<source>/<pipeline>, and the source's default pipeline also at /data/<source>. A pipeline of a source that stores data (a push source) answers with its newest good output -- the address a CKAN resource can link to. A pipeline of an API source stores nothing: the provider is asked at the moment someone calls, with the source's credential and the pipeline's request settings; a pipeline that is switched off, or has no steps, passes the provider's answer through unchanged. Nothing is published until you switch it on, and only an active source answers.
